Publicar Shorts

Ferramenta do canal Quiz Mania

O Publicar Shorts é uma ferramenta de uso pessoal do canal Quiz Mania. Ela envia os vídeos curtos produzidos pelo próprio canal para o YouTube e agenda a publicação de cada um, usando os Serviços de API do YouTube.

A ferramenta roda só no computador de quem administra o canal. Ela não é oferecida ao público, não tem cadastro e não acessa contas de outras pessoas.

Serviços de API do YouTube

Este app usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.
